# Accessibility checklist (binding for all feature agents)

Utilities: `import { useFocusTrap, useAnnounce, announce, useRovingTabindex, usePrefersReducedMotion, useFocusReturn, captureFocus, visuallyHidden } from '@/lib/a11y'`.
Strings: every user-visible string and every `aria-label` goes through `t('feature.section.key')` (`useLocale()`/`useT()` from `@/i18n`). Add keys to all three locale files; run `npm run i18n:check`.

## Keyboard
- Every interactive element is reachable and operable by keyboard; order follows visual order. No positive `tabindex`.
- Use real `<button>`, `<a href>`, `<input>`; never click handlers on `div`.
- Escape closes dialogs, menus and popovers. Arrow keys move within tabs, menus, radio groups (`useRovingTabindex`).
- Skip link (`a11y.skipLink`) is the first focusable element, targets `main#main-content`.

## Focus
- Visible focus ring on every focusable element (>= 3:1 against its surroundings). Never `outline: none` without a replacement.
- Dialogs: `useFocusTrap(ref, open, { onEscape })`; focus moves in on open and returns to the trigger on close.
- After route change, move focus to the page `<h1>` (tabIndex -1) and announce the title.
- Do not steal focus on async updates; use `announce()` instead.

## Contrast and targets
- Text contrast >= 4.5:1 (large text >= 3:1); UI component borders/icons >= 3:1. Use only tokens that Agent A has verified.
- Never use colour alone: readiness bands, status and errors also carry text and/or an icon.
- Touch/click targets >= 44x44px (`min-h-11 min-w-11`), with spacing between neighbours.

## Sinhala and Tamil rendering
- `<html lang>` is kept in sync by i18n. For mixed-language fragments add `lang="en"`/`lang="si"`/`lang="ta"` on the element.
- Font stack must include a Sinhala and a Tamil capable face (e.g. Noto Sans Sinhala, Noto Sans Tamil); check no tofu boxes.
- Use line-height >= 1.6 for si/ta body text (stacked diacritics clip at 1.2). Never set a fixed pixel height on text containers; no `text-transform: uppercase`/letter-spacing on si/ta text.
- Allow 30-40% longer strings: no truncation of labels; buttons wrap or grow.
- Do not concatenate translated fragments; use interpolation (`{{name}}`) and plural suffixes (`_one`/`_other`).

## Motion
- Respect `usePrefersReducedMotion()` (and Tailwind `motion-reduce:`): replace movement with fades/no animation. No auto-playing motion > 5s without a pause control.
- Celebration effects (quests) must be optional and skipped under reduced motion.

## Live regions and status
- Loading: `aria-busy="true"` on the region + `announce(t('a11y.loading'))`; loaded: announce `a11y.loaded` or a specific result.
- Errors: inline message tied with `aria-describedby`; fatal errors `role="alert"`.
- New tutor message: `announce(t('a11y.newMessage'))` (polite).

## Landmarks and headings
- One `<main>`, `<nav aria-label>` (distinct labels for sidebar vs bottom nav), `<header>`. One `<h1>` per page; headings do not skip levels.
- Mark the current nav item with `aria-current="page"`.

## Patterns
- **Tabs**: `role="tablist"` > `role="tab"` (`aria-selected`, `aria-controls`, roving tabindex) and `role="tabpanel"` (`aria-labelledby`). Arrow keys switch focus; Home/End jump.
- **Dialog**: `role="dialog"` (or `alertdialog`), `aria-modal="true"`, `aria-labelledby` -> title, focus trap, Escape closes, background inert/hidden, focus returns to trigger. Close button labelled `a11y.close`.
- **Table**: real `<table>` with `<caption>` (translated), `<th scope="col|row">`; sortable headers are buttons with `aria-sort`; do not use tables for layout. On 390px prefer horizontal scroll container with `tabIndex=0` and a label, or a card list with the same data order.
- **Forms**: visible `<label>` per input, `aria-required`/`required`, errors with `aria-invalid` + `aria-describedby`, `autocomplete` where applicable.
- **Charts**: provide a text summary or data table alternative; do not rely on colour only.
- **Images/icons**: decorative `aria-hidden="true"`; informative have `alt`/`aria-label` (translated). Icon-only buttons need an accessible name.
- **Progress**: `role="progressbar"` with `aria-valuenow/min/max` and a translated label (`a11y.progress`).

## Educational safety wording
- Readiness is shown as a band with its description, never a numeric predicted mark. Wellbeing prompts are private, gentle, non-diagnostic. AI answers show sources.

## Before you mark Done
Tab through the page with the keyboard only; zoom to 200%; test with Sinhala and Tamil selected; enable "reduce motion"; run a screen reader pass on key flows.
